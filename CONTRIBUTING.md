# Contributing to NAUG

Thank you for your interest in contributing to the Northern Azure User Group repository!

## How to Contribute

### 1. **Propose a Talk / Become a Speaker**

We're always looking for speakers! Here's how to submit:

**Submit via:**
- The NAUG organising team (contact details on our [Meetup page](https://www.meetup.com/northern-azure-user-group))
- Or [raise a GitHub issue](../../issues/new) with your proposal

**Include:**
- Talk title
- Abstract (200 words max)
- Your bio (50-100 words)
- Headshot (optional)
- LinkedIn/Twitter/website links
- Technical/AV requirements
- Availability (dates you can speak)

**Timeline:**
- Proposals reviewed 4 weeks before event
- Slide deadline: 1 week before event

### 2. **Contribute to the Repository**

We welcome contributions to improve this repository! Here are some ways you can help:

**Documentation & Content:**
- Fix typos or improve clarity in existing docs
- Add event summaries or speaker slide decks (with permission)
- Expand venue or speaker information
- Improve FAQ or other guides

**Improvements & Suggestions:**
- Suggest new features or improvements (create an issue)
- Report broken links or outdated information
- Help organize or restructure content

**Process:**
1. Create a branch: `git checkout -b improve/description`
2. Make your changes (updates to markdown, adding event content, etc.)
3. Submit a pull request with a clear description of what you've changed and why

### 3. **Suggest Topics or Improvements**

- Found a typo? Create an issue
- Have a topic idea for future events? Create an issue with the `topic-request` label
- Ideas for repo improvements? We'd love to hear them!

## Guidelines

- Keep language inclusive and respectful (see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md))
- Speaker slides should be PDF format
- Event summaries should be concise but informative
- All submissions should be in English

## Questions?

Contact the NAUG organising team via our [Meetup page](https://www.meetup.com/northern-azure-user-group) or [raise a GitHub issue](../../issues/new).
